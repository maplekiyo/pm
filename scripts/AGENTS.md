# Scripts guide

This directory contains local Docker scripts for the Project Management MVP.

- `start.ps1` and `stop.ps1` are for Windows PowerShell.
- `start.bat` and `stop.bat` are for Windows Command Prompt.
- `start.sh` and `stop.sh` are for Mac and Linux shells.

The scripts build and run the `pm-mvp` Docker image on port `8000`.
